# Product screenshots

`dashboard.png` is a Firefox viewport capture of the actual React caregiver
dashboard from local main baseline `530f6bc`, captured on 2026-10-18 UTC at
`http://localhost:5178/?demo=1`. It shows the default “Possible fall · Pending”
scenario, with fictional residents, room layout and in-memory incident data.

The image is intentionally tracked for the product README. It contains no live
resident data or provider credentials and is not evidence of hardware sensing,
model accuracy or a real notification. It has not been generated or retouched.

To refresh it, follow the root README's Docker startup, open the fixture dashboard,
reset to the default scenario, and use Firefox's “Take Screenshot → Save visible”
with the complete desktop map and incident card visible. Recheck that the on-screen
fictional-data notice remains visible before replacing the image.
