# Conservatory ornament

`conservatory-branch.svg` is original vector artwork drawn in code for the Paper
refinement. It interprets the supplied references through fine circular frames,
botanical linework and the established sage/blush palette. It contains no copied
photograph, trading-card artwork, resident information or external resource.

The same SVG is editable in the Paper desktop variant and loaded decoratively in
the app heading. It has no operational or clinical meaning. Keep it outside text
and control areas, omit it where space is limited, and hide it from assistive
technology. The original logo and dashboard restore point remain intact.
